# Бот: бесплатный курс за подписку на канал

Работает **бесплатно**: бот на Render (Free), ученики хранятся в Google Таблице.

## Как работает
1. Человек жмёт /start, бот просит подписаться на канал.
2. «Я подписался ✅» → бот проверяет подписку и сразу шлёт урок 1.
3. Остальные уроки идут по расписанию из `lessons.json` (по умолчанию раз в сутки).
4. Отписался — курс на паузе; подписался обратно — продолжается.
5. Через сутки после урока 6 — оффер платного сообщества.

Бесплатный Render засыпает, если 15 минут к нему никто не обращается. Будят его:
- любое сообщение боту (Telegram сам стучится на сервер);
- скрипт в Google Таблице — раз в час. Поэтому урок может прийти с задержкой до часа.

## Настройка

### 1. Telegram
- @BotFather → `/newbot` → токен.
- Добавь бота **админом** в свой канал (права не нужны, только чтобы видел подписчиков).
- Создай закрытый канал-хранилище, добавь туда бота админом, выложи по посту на урок.
  Перешли каждый пост боту — он ответит `source_message_id`, впиши в `lessons.json`.
- В `lessons.json` → `final_offer.button_url` — ссылка на оплату сообщества.

### 2. Google Таблица
- Открой таблицу «Бот курса — ученики» → **Расширения → Apps Script**.
- Сотри всё, вставь код из `google_apps_script.gs`, заполни `SECRET` и `BOT_URL` (адрес возьмёшь в Render на шаге 3, можно вписать потом).
- Сверху выбери функцию **setup** → ▶ **Run** → разреши доступ (Advanced → Go to… → Allow).
- **Deploy → New deployment** → тип **Web app** → Execute as: **Me**, Who has access: **Anyone** → Deploy. Скопируй URL (`.../exec`) — это `SHEET_URL`.
- Если потом меняешь код скрипта: Deploy → Manage deployments → ✏️ → Version: New version.

### 3. Render
- New → **Blueprint** → выбери репозиторий `course-bot`.
- Заполни: `BOT_TOKEN`, `CHANNEL_ID`, `CHANNEL_URL`, `STORAGE_CHAT_ID`, `ADMIN_IDS`, `SHEET_URL`, `SECRET` → Apply.
- Скопируй адрес сервиса (`https://course-bot-xxxx.onrender.com`) в `BOT_URL` в скрипте таблицы.

Изменил уроки и запушил в GitHub — Render сам выкатит новую версию. Ученики не потеряются: они в таблице.

## Лимит Render
На бесплатном тарифе на весь аккаунт даётся 750 часов в месяц, общих для всех бесплатных сервисов.
Этот бот бодрствует примерно 15–20 минут в час (≈200–250 ч/мес). Если другой бот на том же аккаунте
работает круглосуточно (его постоянно пингуют), вместе они могут выйти за лимит — тогда Render
остановит бесплатные сервисы до конца месяца. Проверить расход: Render → Billing.

## Откуда приходят люди
Давай разные ссылки на бота для разных площадок — метка после `?start=` попадёт в таблицу (колонка `source`) и в `/stats`:
- `https://t.me/ИМЯ_БОТА?start=tiktok`
- `https://t.me/ИМЯ_БОТА?start=insta`
- `https://t.me/ИМЯ_БОТА?start=fb`
- `https://t.me/ИМЯ_БОТА?start=yt`
- `https://t.me/ИМЯ_БОТА?start=channel`
Метка — латиница, цифры, `_` и `-`, до 40 символов. Можно дробить: `tiktok_video12`, `fb_ads_nov`.
Кто зашёл по ссылке без метки — `direct`; кто пришёл до появления меток — «до меток».

## Команды админа
- `/stats` — сколько пришло, подписалось, где отваливаются, сколько дошло до оффера
- `/broadcast текст` или ответом на сообщение — рассылка всем
- `/reload` — перечитать `lessons.json` и таблицу
- переслать пост из канала → бот покажет его ID

## Команды ученика
- `/start` — начать или узнать прогресс
- `/lessons` — заново получить открытые уроки
