# Бот: бесплатный курс за подписку на канал

## Что делает
1. Человек жмёт /start, бот просит подписаться на канал.
2. После нажатия «Я подписался ✅» бот проверяет подписку и сразу присылает урок 1.
3. Остальные уроки приходят по расписанию из `lessons.json` (по умолчанию раз в 24 часа).
4. Перед каждым уроком бот снова проверяет подписку. Отписался — курс на паузе, подписался обратно — продолжает с того же урока.
5. Через сутки после урока 6 приходит предложение вступить в платное сообщество за $50 в месяц, с кнопкой-ссылкой.

## Настройка (15 минут)
1. **Создай бота** у @BotFather → `/newbot` → скопируй токен.
2. **Добавь бота админом** в свой публичный канал (без каких-либо прав — нужно только чтобы он видел подписчиков).
3. **Уроки.** Создай закрытый канал-хранилище, добавь туда бота админом и выложи по посту на урок (видео + подпись).
   Перешли каждый пост боту — он ответит ID канала и `source_message_id`. Впиши их в `lessons.json`, а поле `text` оставь пустым или убери.
   (Можно и без хранилища: только текст в `text`, в нём работают теги `<b>`, `<i>`, `<a href="...">`.)
4. В `lessons.json` → `final_offer` поставь свою ссылку на оплату (Tribute, Boosty, страница Stripe — что угодно).
5. Скопируй `.env.example` в `.env` и заполни.

## Запуск
```
pip install -r requirements.txt
python bot.py
```
Чтобы бот работал круглосуточно, нужен сервер: любой VPS за $4–6 в месяц (Hetzner, DigitalOcean) или Railway / Render.
Не закрывай: база `users.db` хранит, кто на каком уроке.

## Команды админа
- `/stats` — сколько человек пришло, подписалось, на каком уроке отваливаются, сколько дошло до оффера
- `/broadcast текст` — рассылка всем; или ответь `/broadcast` на любое сообщение (видео, фото), и бот его разошлёт
- `/reload` — перечитать `lessons.json` без перезапуска
- переслать пост из канала → бот покажет его ID

## Команды пользователя
- `/start` — начать или узнать прогресс
- `/lessons` — заново получить все уже открытые уроки
